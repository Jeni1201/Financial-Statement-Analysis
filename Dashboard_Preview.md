# Dashboard Preview
### Dashboard Features
- Dynamic Year and Company filtering
- Financial performance comparison across 5 Indian listed companies (FY2022–FY2026)
- Dynamic trend analysis using Field parameters (Total Revenue, Total Profit, Total Assets)
- Company ranking framework based on Revenue, Profit, and Assets
- Drill-through company analysis for ROE, ROA, Debt-to-Equity, and Cash Conversion (CFO-to-Profit)
